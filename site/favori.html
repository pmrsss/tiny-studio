Le favori « Ranger dans Tiny Studio »

Sur la page d’un produit, un clic sur ce favori lit la page ouverte et ouvre Tiny Studio avec l’article déjà rempli. Il marche aussi sur les sites qui refusent la lecture par lien, comme Zara ou Zalando.

Sur ordinateur

  1. Affiche la barre des favoris : dans Safari, menu Présentation, « Afficher la barre des favoris » ; dans Chrome, ⌘ Maj B.
  2. Fais glisser ce bouton jusqu’à la barre des favoris :
+ Ranger dans Tiny Studio

Sur iPhone, dans Safari

  1. Copie le code du favori :

  1. Ajoute cette page à tes favoris : bouton de partage, puis « Ajouter un signet ».
  2. Ouvre tes signets, touche « Modifier », puis le signet que tu viens d’ajouter.
  3. Renomme-le « Ranger dans Tiny Studio », efface son adresse et colle le code à la place.
  4. Sur la page d’un produit, ouvre tes signets et touche « Ranger dans Tiny Studio ».
